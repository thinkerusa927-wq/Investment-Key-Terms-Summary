# Key Terms Summary格式参考

## 1. 文件定位

- 文档类型：投资/融资交易文件的管理层摘要，不是法律意见、风险清单或逐条条款释义。
- 默认读者：CEO、总法律顾问、投资决策层。
- 默认语言：中文；协议名称、主体名称及必要术语可保留英文。
- 目标篇幅：原则上1页，内容多时可1.5页；内容确实较多时最多2页。

## 2. 默认版式

以`../assets/Key Terms Summary模板.docx`为设计权威：

- A4纵向，单节。
- 页边距：左右约0.86英寸，上下约0.76英寸。
- 标题：`项目名称 - 交易文件核心条款总结`，居中、加粗。
- 日期：`YYYY.MM.DD`，居中，置于标题下方。
- 主体：三列表格，列名为`# / 事项 / 内容`。
- 列宽比例约为4.4% / 18.6% / 77.0%。
- 表头浅灰底（参考色BEBEBE），黑色细边框；表头和单元格垂直居中。
- 正文约10.5磅，保持模板字体和段落节奏；事项列加粗。
- 内容列使用与`#`列区分的全角括号自动编号，格式为`（1）`、`（2）`；每条以简短下划线标签开头，例如`我方投资：`、`回购权：`。
- 如有第二页，第二页必须重复表头；不另设封面、目录、脚注或页脚说明。

## 3. 候选信息架构

下表是内部取材菜单，不是默认目录。除“交易经济与股权”通常必写外，其余事项均按项目取舍；不得为了凑齐主题而加入CEO没有决策增量的条款。

| 候选事项 | 何时进入正文 |
|---|---|
| 交易经济与股权 | 我方签约/持股主体、投资或购买价、注册资本/股数、投后持股；估值或完整cap table仅在影响判断时写 |
| 核心业务与交易边界 | 业务范围、品牌/IP、门店或资产边界本身是本次投资的重要前提 |
| 项目特有合作 | 海外区域、JV比例、并表、运营主导、资源协同等本项目专属安排 |
| 公司治理与控制 | 董事席位、提名权、实际具有区分度的否决或同意权 |
| 退出与经济保护 | 回购、清算优先、具有实质退出意义的共售/拖售及其核心经济结果 |
| 创始人或股东承诺 | 不竞争、全职、资源/IP投入、业务机会归属等直接保护投资标的价值的义务 |
| 其他惯常投资人权利 | 协议已约定的分红权、知情权和反稀释权合并为一句结果性概括；未约定的不补写 |

### 结构调整

- 同时包含SPA、SSA和SHA：正文按文件分组并依次排列，在每个事项名称后标注`（SPA）`、`（SSA）`或`（SHA）`；不另设合并三列的协议分组行。
- SPA老股转让价款与SSA增资款的金额及收款主体必须在底稿中分别核验；只有该区别对CEO具有决策增量时，才在正文中分别说明。
- 留空事项和协议未直接写明的推算值均不写入最终Word。
- 多轮或多类股份：优先把股权结构做成同一条中的紧凑并列，不另起大表，避免版面碎裂。
- 默认不单列交割安排、争议解决、一般违约或文本校核；只有用户明确要求，或存在直接影响签署/决策的异常安排时才增加。
- 普通转股限制、优先购买、优先认购、普通财务安排及其他惯常条款默认不写；分红权、知情权和反稀释权按候选信息架构的要求合并为一句结果性概括。

## 4. 密度控制

- 核心交易事项可写2至3条；其他事项原则上1条，确有两个独立商业结果时最多2条。
- 每条通常1个短句；只有第二句能改变CEO对权利价值的判断时才保留。
- 同一事项若需要连续解释行权条件、通知步骤和期限，删除这些程序细节，仅概括描述事项本身。
- 同一机制在SSA和SHA重复时，仅保留SHA里的内容。
- 普通保密、通知、完整协议、可分割性、份数等惯常条款默认不写，除非有异常安排或直接影响决策。
- 如有第二页，第二页内容宜控制在半页以内；超过2页说明筛选或改写仍不够凝练。但即使只有1页，也要检查单个事项是否仍写得过满。

## 5. 模板使用规则

1. 复制模板到任务工作目录，绝不修改技能内原件。
2. 替换标题、日期和表格正文；保留页面系统、表头、列宽、底色、边框和字体。
3. 用真实自动编号，不用手打项目符号或换行伪造列表；`#`列按模板编号，内容列的分项编号可按参考文件保留或隐藏，不得用手打字符冒充自动编号。
4. 行高允许自适应，禁止固定行高造成裁切。
5. 内容较长时先压缩文字，再调整行距/段前后；字号不得低于模板可读基准。
6. 最终文件名：`项目名称 - 交易文件核心条款总结_YYYYMMDD.docx`。

## 6. 视觉验收

- 标题和日期居中，表格与页边距对齐。
- 事项列无尴尬的单字孤行，英文主体名称和金额不被异常拆分。
- 表头在续页重复，边框连续，行内容不重叠、不裁切。
- 第一页接近满页，第二页不超过约半页；整体仍有自然留白。
- 所有页面在100%比例检查通过后才交付。
